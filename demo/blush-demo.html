The design philosophy

Minimalist, spacious, semantic.

Semantic HTML should be naturally beautiful, without cluttering tags with utility classes. Generous spacing and fluid typography give it an airy feel; ARIA attributes and role drive every visual state.

Attributes say what it is. Classes say how it looks.

Why measure matters

Text in main and article stops at a readable line length.

Long lines tire the eye. Blush caps paragraphs, lists and quotes at --measure (65ch by default), so a page of prose stays comfortable on a wide screen while headings, figures, tables and grids keep the full width.

Change the dial on any container: style="--measure: 48ch". The vertical rhythm between blocks follows the type scale, so spacing never needs a utility.

Generous spacing is not decoration. It is how a page breathes.

Tone and shape

Classes only add tone.

Tone classes set --tone (it never leaks to children). On a button the tone is the fill; on any other element it is the text color.

What is Blush?

A reset with superpowers: a classless CSS framework built on Tailwind CSS v4.

Does it conflict with Tailwind?

No. Tailwind sits underneath: Blush's tokens are Tailwind tokens, and its class names avoid Tailwind's.
